# 硝子の床 MOD（Glass Floor）

普段は継ぎ目のない透明なガラス床でありながら、スイッチや足元をきっかけに光の回路とネオンが浮かび上がる、薄さ 1 ピクセルのガラス床シリーズ（全 17 色 × 8 バリエーション ＝ 136 ブロック）を追加する Minecraft 1.20.1 (Forge) 用小規模 MOD です。

## ダウンロード（リファレンスビルド）

右側の **[Releases](../../releases)** から最新の `glassfloor-1.2.1.jar` をダウンロードし、Minecraft の `mods` フォルダへ配置してください。

- **対応バージョン**: Minecraft `1.20.1` / Forge `47.4.0` 以降
- **推奨環境**: Embeddium / Rubidium + Oculus（OptiFine は非推奨）
- **競合対策**: 単体変換レシピの競合回避のため Polymorph の併用を推奨

## 主な特徴

- **8 種類のバリエーション（全 17 色対応）**:
  1. 硝子の床（通常・明るさ 0・完全透過）
  2. 発光硝子の床（常時発光・明るさ 14）
  3. レッドストーン硝子の床（ON 時に各色の光線が流れる配線床）
  4. レッドストーン発光硝子の床（ON 時に外周ネオンが発光・明るさ 15）
  5. 硝子素子 4 種（木 / 石 / 軽量 / 重量の感圧板互換・静音センサー）
- **軽量設計**: `BlockEntity` や Mixin を一切使用しないため、大型 MOD パック環境でも軽量に動作します。
